# Habla del agente

Preparar un texto aprobado de hasta 400 caracteres con expression_score en modo speech. Elegir una voz del dispositivo realmente disponible; preferir una voz local. El uso de voces remotas requiere elección explícita e informa el envío del texto al proveedor. Comprobar inicio y fin; una solicitud preparada no acredita audibilidad. Ofrecer texto y limitación si el navegador no tiene voz. Permitir detener; no leer automáticamente datos privados ni clonar voces o prometer un acento no verificado.

## Herramientas y prueba

Consultar expression_skills y preparar con expression_score. El MCP guarda el plan; el navegador activo reproduce. Registrar eventos como declaraciones de la interfaz, sin confundirlos con verificación de sonido audible o aprobación de un observador. Probar falta de soporte, cancelación y resultado dentro del alcance declarado.

## Procedencia

Implementación propia de Fábrica de Agentes IA, mediante Web Speech, Web Audio y animación web. No incorpora canciones, voces clonadas, coreografías ni recursos ajenos.
